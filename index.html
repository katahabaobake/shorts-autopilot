shorts-autopilot

▶ Uses YouTube API Services

shorts-autopilot is a personal desktop tool (single user, runs locally on the operator's Mac) that manages the operator's own YouTube channels:

  • Uploads the operator's own finished videos on a daily schedule (YouTube Data API: videos.insert)
  • Posts one first comment on each of the operator's own videos (commentThreads.insert)
  • Checks the operator's own upload lists to avoid duplicate uploads (channels.list, playlistItems.list, videos.list)
  • Reads the operator's own channel analytics (YouTube Analytics API, read-only)

It is not offered to other users. By using this tool you agree to the YouTube Terms of Service. See the Google Privacy Policy.
