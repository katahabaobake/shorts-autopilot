Privacy Policy

Last updated: 2026-09-29

1. YouTube API Services

shorts-autopilot uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy also applies.

2. Who uses it

shorts-autopilot is a personal tool used only by its operator to manage the operator's own YouTube channels. It has no other users.

3. Data accessed

After the operator authorizes the tool with Google OAuth, it accesses, for the operator's own channels only:

  • Uploading videos and setting their title, description and scheduled publish time
  • Posting one first comment on the operator's own videos
  • The upload list, video titles, video IDs and privacy status (to avoid duplicate uploads)
  • Channel and video analytics such as views and audience retention (read-only)

It does not access any other user's data and does not read or store other people's comments.

4. How data is used, stored and shared

OAuth tokens and the data above are stored only on the operator's own computer and used only for the purposes above. Data is never sold, shared with third parties, or used for advertising. No cookies or tracking are used.

5. Retention and deletion

Stored analytics data is refreshed regularly and kept no longer than needed. When authorization is revoked, the stored OAuth token and all data obtained through YouTube API Services are deleted from the operator's computer within 7 days. Authorization can be revoked at any time on the Google security settings page (Google Account > Security > Third-party apps with account access).

プライバシーポリシー

shorts-autopilot（以下「本ツール」）は YouTube API サービスを使用しています。利用には YouTube 利用規約 が適用され、Google プライバシーポリシー も適用されます。

本ツールは運営者本人が管理する YouTube チャンネルの運用だけに使う個人用ツールで、ほかの利用者はいません。Google の認可を通じて、運営者のチャンネルへの動画のアップロード（タイトル・説明文・公開日時の設定）、運営者の動画への最初のコメントの投稿、投稿一覧の確認（同じ動画を二重に投稿しないため）、再生数・視聴維持率などの統計の読み取りを行います。

取得した情報と認可トークンは運営者のコンピューター上にだけ保存し、上記の目的だけに使います。第三者への提供・販売・広告目的の利用は行いません。

認可を取り消した場合、保存したトークンと YouTube API サービスから得たデータは 7 日以内に削除します。認可は Google のセキュリティ設定ページ からいつでも取り消せます。
