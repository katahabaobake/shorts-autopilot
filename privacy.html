プライバシーポリシー

shorts-autopilot（以下「本ツール」）は、運営者本人が管理する YouTube チャンネルの運用だけに使う個人用ツールです。

取得する情報

Google アカウントで認可したとき、YouTube Data API と YouTube Analytics API を通じて次の情報にアクセスします。

  • 運営者のチャンネルへの動画のアップロード、タイトル・説明文・公開日時の設定
  • 運営者のチャンネルの動画の再生数・視聴維持率などの統計

情報の使い方と保存

取得した情報と認可トークンは、運営者のコンピューター上にだけ保存し、投稿と統計の確認のためだけに使います。第三者への提供・販売・広告目的の利用は行いません。

削除

認可は Google アカウントの権限設定 からいつでも取り消せます。取り消すと本ツールは情報にアクセスできなくなります。

本ツールは YouTube API サービスを使用しており、YouTube 利用規約 と Google プライバシーポリシー が適用されます。

Privacy Policy

shorts-autopilot is a personal tool used only by its operator to manage the operator's own YouTube channels. Through the YouTube Data API and YouTube Analytics API it uploads videos to and reads statistics of the operator's own channels. Data and OAuth tokens are stored only on the operator's computer, used only for these purposes, and never shared, sold, or used for advertising. Access can be revoked at any time at Google Account permissions. This tool uses YouTube API Services; the YouTube Terms of Service and Google Privacy Policy apply.
